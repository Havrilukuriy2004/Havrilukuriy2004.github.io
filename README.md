# Академічний сайт Юрія Гаврилюка / Academic website of Yurii Havryliuk

Двомовний статичний сайт (українська в корені, англійська в `en/`) для GitHub Pages: головна сторінка в стилі CV,
дослідження (магістерська, бакалаврська, міжбанківські мережі, ESG), блог, аналітика (інтерактивний дашборд
банківської системи та Excel-інструменти), публікації, викладання і Фінансовий клуб. Шрифт Arial, формули LaTeX (MathJax).

## Структура

```
content/
  site.yaml            профіль, освіта, досвід, нагороди (uk/en)
  research/*.yaml      сторінки дослідницьких проєктів: анотація, результати, матеріали
  posts/<назва>/uk.md  записи блогу; поруч en.md — англійська версія
  collections.yaml     сторінки курсів і категорій клубу (лекції, завдання, кейси)
  teaching.yaml        сторінка «Викладання»
  club.yaml            сторінка Фінансового клубу, аналітичні записки
  analytics.yaml       дашборд, Excel-інструменти, набори даних
  publications.yaml    публікації
  blog.yaml            розділи блогу
  macros.yaml          LaTeX-макроси (\CoF, \GAP, \rkey ...)
files/                 усі файли для завантаження (PDF, XLSX, ZIP, CSV)
static/                style.css, dashboard.js
build.py               генератор: python build.py → _site/
tools/prepare_assets.py службовий скрипт, яким файли з ваших папок розкладено у files/
```

Кожне текстове поле в YAML має дві мови: `{uk: "...", en: "..."}`. Якщо англійського тексту немає, показується український.

## Як додати файл

1. Покладіть файл у `files/...`, наприклад `files/club/intro-economics/lecture_01.pdf`.
2. Допишіть рядок у потрібну групу в `collections.yaml` або `research/*.yaml`:
   ```yaml
   - {title: {uk: "Лекція 1. Вступ", en: "Lecture 1. Introduction"}, file: club/intro-economics/lecture_01.pdf}
   ```
3. Якщо файлу ще немає, на сайті з'явиться позначка «буде додано», а щойно файл з'явиться в `files/`, посилання
   стане активним автоматично.

## Як додати запис у блог

Створіть теку `content/posts/<коротка-назва>/` з файлами `uk.md` і `en.md`:

```markdown
---
title: Назва
date: 2026-12-01
order: 1
section: master        # master | bachelor | interbank | esg | club
summary: Один-два речення для списку записів.
---

Текст у Markdown. Формули: $\CoF_{it}$, \begin{equation} ... \label{eq:x} \end{equation}, посилання \eqref{eq:x}.
Рисунок з роботи (нумерується автоматично): {{fig 2.21}} або {{fig bachelor:2.13 | власний підпис}}
Будь-яке зображення: {{img master/figures/en/S3_F03_allocation.png | Підпис | Джерело: ...}}
Таблиця з роботи: {{tab 2.6}}, частина таблиці: {{tab 3.32 | Назва | rows=2-6,11 | cols=0,1}}
Markdown-таблиця з нумерованою назвою: рядок «Таблиця: Назва» безпосередньо перед таблицею
Сітка анімацій: {{gallery шлях1.gif :: підпис ;; шлях2.gif :: підпис}}
Посилання на сторінку сайту: [текст]({{site}}/research/master.html)
```

Блоки `::: definition Назва ... :::` (також `proposition`, `hypothesis`, `remark`, `example`) нумеруються автоматично.
`draft: true` у шапці ховає запис.

## Як зібрати локально

```bash
pip install markdown pyyaml
python build.py
cd _site && python -m http.server 8000   # відкрийте http://localhost:8000
```

Дашборд завантажує дані через `fetch`, тому відкривайте сайт через веб-сервер, а не подвійним кліком по файлу.

## Як опублікувати на GitHub Pages (Havrilukuriy2004.github.io)

1. На GitHub створіть **публічний** репозиторій з назвою `Havrilukuriy2004.github.io`.
2. Завантажте в нього вміст цієї теки (без `_site/`). Через браузер GitHub приймає файли до 25 МБ, а
   `files/master/results/Results_UA.zip` важить 29 МБ, тому зручніше використати **GitHub Desktop** або git:
   ```bash
   git init && git add . && git commit -m "Academic website"
   git branch -M main
   git remote add origin https://github.com/Havrilukuriy2004/Havrilukuriy2004.github.io.git
   git push -u origin main
   ```
3. У репозиторії: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Через 1–2 хвилини сайт буде доступний за адресою **https://havrilukuriy2004.github.io/**,
   англійська версія — **https://havrilukuriy2004.github.io/en/**. Після кожного коміту сайт перебудовується сам
   (`.github/workflows/deploy.yml`).

Обмеження GitHub: файл до 100 МБ, рекомендований розмір репозиторію до 1 ГБ (зараз ≈180 МБ).
